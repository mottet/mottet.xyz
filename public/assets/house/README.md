The botanical wallpaper JPEG is the image supplied by the site owner, copied unchanged from:

https://media.adeo.com/mkp/3d177633a7bcfdcc32a82f6f0fbcd2f4/media.jpeg

`houseScene.js` crops the clean repeating area through an SVG viewBox, excluding the white product background and rolled edge. The same physical pattern scale is used on the side and rear walls.

The SVG applies a static color matrix to the source image before repeating and projecting it: blue-green foliage becomes muted sage and olive, yellow flowers become soft ochre, and the cream ground becomes warm stone. This matches the room's existing wall palette while preserving the original botanical drawing. Wall lighting is applied afterward.
